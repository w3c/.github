# Reporting a security vulnerability

Please report suspected security vulnerabilities privately.

## Specifications

In the specification's GitHub repository, open **Security and quality** and
select **Report a vulnerability**. If GitHub reporting is unavailable, email
[vulnerability-disclosure@w3.org](mailto:vulnerability-disclosure@w3.org).
See [Section 3.1 of the disclosure policy](https://www.w3.org/TR/security-disclosure/#reporting-a-vulnerability-in-a-w3c-standard).

## Software and tooling

For vulnerabilities in project code, use the project's private reporting
channel, such as **Report a vulnerability** in its GitHub repository.

## Websites and infrastructure

For vulnerabilities in W3C-hosted websites, services, or infrastructure, email
[openbugbounty@w3.org](mailto:openbugbounty@w3.org), the W3C Systems contact
listed in [security.txt](https://www.w3.org/security.txt).

## Unsure where to report?

If you cannot use the relevant channel or are unsure where to report, email
[vulnerability-disclosure@w3.org](mailto:vulnerability-disclosure@w3.org).
